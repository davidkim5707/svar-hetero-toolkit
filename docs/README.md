# Documentation

| File | Contents |
|---|---|
| `options.md` | Every field of the `options` struct that the samplers and their routines read, with its default, its type, and its meaning. It also gives the grammar of the sign restriction strings, the sub-fields of the zero and narrative restrictions, and the workspace variables a driver must set. |
| `output.md` | Every field of the `output` struct that the samplers write, with its dimensions and the condition under which it is written. It opens with the fields a new user needs first. |

Both files were written from the code, and the tables name the file that reads or writes each field.
